# Niro v0.1.53

## Summary

This release defines Niro Community Edition as free-of-charge proprietary
software distributed in binary form and removes the contradictory Apache and
FSL license claims from the public distribution.

## Changes

- Added the complete Niro Community Edition License Agreement.
- Aligned README, NOTICE, release archives, and MCPB license metadata.
- Included LICENSE and NOTICE in both platform archives and `niro.mcpb`.
- Identified the public repository as the documentation and binary-distribution
  surface rather than a product-source repository.

## Security

No Niro runtime security behavior changed. The release clarifies the legal and
trust boundary for the closed-source binary.

## Compatibility and upgrade

There are no CLI, MCP, configuration, or runtime compatibility changes.
Customers installing `v0.1.52` or earlier should upgrade because those archives
contain obsolete, contradictory licensing metadata.

## Known issues

- `checksums.txt` covers the platform archives but does not yet include
  `niro.mcpb`.
- Release artifacts do not yet include detached signatures, a public binary
  provenance attestation, or an SBOM.
